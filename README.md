# SummerVacation
A vibe-coded .NET MAUI app to add narration to your photos.
Featuring:
- Transcription of audio files to text
- Saving audio files and text (in the same directory as the photos) for later retrieval
- Embedding audio information in .JPG comments
- Slideshow mode

Initial version will focus on Android and Windows, with basic photo viewing, audio recording, and playback.
Features planned for future iterations:
- Code clean-up and SRP refactoring into more specialized classes
- Add/test functionality for iOS, Mac, web(?) with Google Photos or One Drive photos, and other platforms
- Embedding info/narration summary in MP3 ID3 tags
- Stand-alone player app that can read any directory and look for photos tagged with audio links
